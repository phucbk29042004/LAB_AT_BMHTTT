- Mã số sinh viên: 1150070035 
- Tên bài Lab: Nhận diện và ứng phó các mối đe dọa đến an toàn thông tin (Lab 3) 
- Nội dung đã thực hiện: Nội dung đã thực hiện: Bài thực hành dùng máy ảo Windows Server 2022 (Desktop Experience) thay cho Windows 11 25H2 theo đề gốc, do điều kiện môi trường sẵn có. Đã hoàn thành TH1 đến TH4: lập risk register và phân loại 5 nguồn đe dọa (TH1); kiểm thử EICAR để xác nhận Defender phát hiện/chặn đúng (TH2); tạo tài khoản lab3user, sinh log đăng nhập đúng/sai qua Event ID 4624/4625/4648 và đổi mật khẩu để kiểm chứng (TH3); cài Sysmon, tạo persistence lành tính (Run key và Scheduled Task) cùng HTTP listener trên 127.0.0.1:8080, phát hiện qua Autoruns/Sysmon/Process Explorer (TH4). Các tình huống TH5, TH6, TH7 và bước cleanup cuối bài chưa thực hiện.
- Kết quả thực hiện: TH1 PASS — risk register đủ 5 dòng, 5 tình huống được phân loại đúng theo định nghĩa. TH2 PASS — Real-time Protection luôn bật; có detection EICAR trong Protection history. TH3 PASS — có Event 4624/4648 cho đăng nhập hợp lệ, Event 4625 cho lần nhập sai; credential cũ hết hiệu lực sau khi đổi mật khẩu. TH4 PASS — LAB3_Run_Demo và LAB3_Persistence_Demo được phát hiện qua Autoruns/Sysmon; listener 8080 chỉ bind 127.0.0.1, PID khớp qua Process Explorer. TH5, TH6, TH7 — chưa làm được. Cleanup/phục hồi/verify — chưa làm được
- Các lưu ý cần thiết để kiểm tra hoặc chạy lại bài làm: Môi trường dùng Windows Server 2022 thay Windows 11, các lệnh PowerShell/Sysmon/Autoruns/Process Explorer hoạt động tương đương, không đổi cú pháp. File www/index.html không có sẵn trong gói dữ liệu nhận được, đã tạo bổ sung thủ công để HTTP server hoạt động. Cấu hình sysmon-lab.xml dùng onmatch="exclude" với danh sách rỗng, nghĩa là ghi lại toàn bộ sự kiện, không loại trừ gì. Tài khoản lab3user tạo riêng cho bài lab, không dùng dữ liệu cá nhân thật.
