- Tên bài Lab: Xây dựng chính sách Web Protection trên mô hình pfSense + Web Proxy (Lab 7)
- Nội dung đã thực hiện:
Bài thực hành kế thừa hạ tầng mạng từ Lab 6 trên môi trường VMware Workstation. Mô hình gồm Firewall pfSense CE, Domain Controller DC01 (Windows Server 2022, đóng vai trò DNS Server), DMZ-WEB là Ubuntu Server chạy Nginx để mô phỏng các website, và các máy trạm Client-A, Client-B (Kali Linux/Windows 10).
